Retrieval evaluation

Measure whether known relevant documents appear in the gateway's retrieved results.

Evaluation set

Enter questions and the exact document IDs expected to answer each one. Hit rate counts cases with any expected document in the top K; recall measures expected document coverage; reciprocal rank rewards an expected document appearing earlier. Latency includes embedding and Atlas search. The workbench evaluates retrieval only; it does not call the chat model or judge answer correctness.

Enter the actual GATEWAY_API_KEY secret value, not the text “GATEWAY_API_KEY”. Do not add the “Bearer ” prefix; the page adds it. Restart the gateway after changing its authentication configuration.
Each case needs a query and one or more exact expected_document_ids. Maximum 100 cases per run.
