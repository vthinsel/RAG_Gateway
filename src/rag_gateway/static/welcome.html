Gateway tools and endpoints

Chunks management Review tenant statistics and documents; remove indexed content. Document loader Upload files or folders, or scan an allowed directory on the Gateway host. Ollama management Manage installed models, context variants, and models running on the Ollama server. Retrieval evaluation Measure retrieval hit rate, recall, ranking, and latency against known source documents. RAG playground Ask a question, inspect retrieved evidence, or compare it with a generated answer. Live API monitoring Watch recent requests, in-flight calls, response status codes, and durations. Environment settings Configure application settings and persist them to the environment file. API documentation Explore the OpenAPI endpoints and request schemas. Liveness endpoint Check whether the Gateway process is responding. Readiness endpoint Check whether required configuration and Atlas connectivity are available.
